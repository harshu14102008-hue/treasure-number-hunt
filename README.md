# Treasure Number Hunt Game

## 1. Project Description
Treasure Number Hunt is a Python-based guessing game in which the computer randomly selects a secret number. The player must find the hidden number within a limited number of attempts using the hints provided by the computer.

## 2. Technologies Used
- Python 3
- Random Module

## 3. Features
- Three difficulty levels: Easy, Medium and Hard.
- Random number generation.
- Hints such as Too High, Too Low and Very Close.
- Limited attempts and score calculation.
- Scoreboard and replay options.

## 4. Game Rules
1. Select a difficulty level.
2. Guess the hidden number within the given range.
3. Follow the hints provided by the computer.
4. Find the treasure before all attempts are used.
5. Earn points based on your performance.

## 5. How to Run

Save the Python code as `treasure_hunt.py` and execute:

```bash
python treasure_hunt.py
```
